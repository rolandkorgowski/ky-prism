# Security reporting

Report a suspected vulnerability through GitHub's private vulnerability
reporting for this repository when enabled. For a public report, avoid
including private photos, EXIF location data, local account paths, keys or
other personal material. Provide a minimal non-private reproducer instead.

Image decoders process untrusted input. Keep distribution decoder libraries,
Qt and drivers updated. ky-prism does not claim to detect malware or make
arbitrary malformed images harmless. The installer does not request root for
building or running the viewer. No analytics/update service is installed.
